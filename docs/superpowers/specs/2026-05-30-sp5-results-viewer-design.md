# SP5 — Results Viewer + Surrogate Predictor Desktop Tab

## Goal

Add a "Resultados" tab to the desktop app that:
1. Shows all prediction maps (SWMM, ML tabular, Surrogate CNN) in a three-folder browser
2. Displays the selected image inline using Pillow
3. Includes a Surrogate Predictor section — runs `predict_surrogate_from_multiplier()`,
   saves the map, and auto-displays it in the viewer

---

## Context

The original SP5 spec (2026-05-29) was designed for the early-warning CNN (SP3 original)
which required a SWMM Parquet as input. That approach is obsolete — the surrogate CNN
(`predict_surrogate_from_multiplier()`) and map generator (`plot_surrogate_map()`) are
already implemented and working. SP5 now integrates them into the desktop.

The surrogate maps are currently saved to the project root — SP5 moves them to

### Components

**Left panel — `ttk.Treeview`:**
- Three root nodes: "SWMM", "ML Tabular", "Surrogado (CNN)"
- Children: filenames (without extension) found by scanning the three directories
- Selection triggers image display in the right panel
- "↺ Actualizar" button rescans all directories

**Right panel — image display:**
- `ttk.Label` with `PIL.ImageTk.PhotoImage`
- Image scaled to fit the panel while preserving aspect ratio
- Placeholder text "Selecciona una imagen" when nothing is selected

**Predictor Surrogado section:**
- `ttk.Entry` for the inflow multiplier (float, validated)
- `ttk.Entry` + "Buscar..." button for the `.inp` file path (pre-filled with `DEFAULT_INP_FILE`)
- "Predecir y mostrar" button — disabled if surrogate artifacts don't exist
- Runs in a background thread (same `_run_in_thread` pattern as existing tabs)
- On completion: saves map → refreshes tree → auto-selects and displays new image

## Surrogate map save location

`predict_surrogate_from_multiplier()` currently returns a DataFrame. The map is
generated by the caller. SP5 standardizes the save path inside `plot_surrogate_map()`:

New default output path when `output_path` is not provided:
```python
DEFAULT_SURROGATE_MAPS_DIR = DEFAULT_TEMPORAL_ARTIFACTS_DIR.parent / "maps"
# → data/networks/chico_hydro-qx1/results/temporal/maps/
```

`plot_surrogate_map()` gains an optional `output_path` — if None, saves to
`DEFAULT_SURROGATE_MAPS_DIR / f"surrogate_map_qx{multiplier:.2f}.png"`.

---

## Auto-display on prediction complete

When "Predecir y mostrar" finishes:
1. Map saved to `DEFAULT_SURROGATE_MAPS_DIR`
2. Tree refreshed (Surrogate NN folder rescanned)
3. New map auto-selected in the tree
4. Image displayed in right panel
5. Notebook switches to "Resultados" tab

The same auto-refresh also happens when the existing SWMM simulation or ML prediction
tabs complete — they call a shared `_refresh_results_tree()` method on the app.
