# Paridades de densidad (versión anterior)

Esta carpeta conserva una variante de la presentación anterior que usa hexágonos coloreados por cantidad de pares, con escala logarítmica para la densidad. La diagonal roja `y = x` significa volumen predicho igual al volumen SWMM.

La paridad global contiene 410.814 pares corrida–nodo. La vista condicional contiene 131.502 nodos inundados por SWMM (≥1 m³); sus RMSE no sustituyen los RMSE globales.

La presentación vigente usa puntos azul/naranja y el formato oscuro de la referencia del 20 de octubre: [documentación de la versión final](../formato_20_10_puntos_final/README.md).
