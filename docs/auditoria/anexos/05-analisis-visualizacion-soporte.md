### 1.2 Method

- Line-by-line reading of the modules above, plus read-only executable checks.
- All scripts are in the scratchpad (`...\scratchpad\v01_*.py` ... `v15_*.py`) and are run with `venv\Scripts\python.exe` from the repo root.
- Project files written: only this annex. No code, `config.yaml` or `outputs/` was modified. No commit was made. The full pytest suite was not run.
- The real DBs and data were opened in read-only mode (`mode=ro`). To test `create_schema`, a **copy** of `outputs/training_v17.sqlite3` was made with the `backup` API in the scratchpad (`copia_v17.sqlite3`, 55 MB) and the test was run only on the copy.
- Transparency statement: opening the v17 DB in `ro` mode on a WAL-mode database can refresh the date of `outputs/training_v17.sqlite3-shm` (an ephemeral index file; it currently shows the date Oct-10 16:57). The DB content did not change (`-wal` is still 0 bytes).
- What could not be checked is marked **not verified**.
